[oh-my-pi (omp)](https://github.com/can1357/oh-my-pi) コーディングエージェント向けのモダンな Web UI です。ローカルの omp セッションを読み込み、ブラウザから対話、プロジェクト閲覧、設定管理、ファイルプレビューを行えるワークスペースを提供します。

## このフォークの変更

[hsiatein/ompweb](https://github.com/hsiatein/ompweb) は
[kahme247/ompweb](https://github.com/kahme247/ompweb) を基にしています。

と現在のソースを比較し、追加機能と関連修正を **6 分野・53 項目**に整理しました。
コミット数やファイル数ではなく機能の分類です。上流由来の機能は別に記載しています。

| 返信・処理履歴のファイルと画像 | 元のセッションでパス、`file://`、親ディレクトリー相対リンク、永続化された `artifact://` を解決。処理履歴の相対ツールパスはセッションの作業ディレクトリーを基準とし、末尾の読み取りセレクターを除去して Windows ドライブとファイル名の記号を保持。内部ツール URI は通常テキストで表示します。`xd://open_file` とセッション間の文脈を修正し、画像エラーを明示。外部参照はセッション単位で対象ファイルだけに読取りを許可し、ディレクトリー・編集の権限制約を維持します。 |

### 対話・自動化・認証

| 追加 / 変更 | 内容と制約 |
| --- | --- |
| 後で送信 | 既存セッションへのテキスト送信をプリセット、日時、現在モデルの報告された 5 時間枠リセットの 1 分後に予約。ページ終了/再起動後も保存し、期限超過分は起動時に送信。即時送信、取消、手動再試行に対応、最大 30 日先まで。 |
| 定期タスク | 一回、間隔、毎日、毎週のプロンプトを既存または毎回新しいセッションへ送信。停止/編集/削除/即時実行、履歴、新規セッションのモデル・思考・advisor・保持数・制限時間を設定。既定は直近 10 回保持、60 分で中止。 |
| Webhook | タスクに `POST /api/hooks/<token>` を発行し、URL 更新と最大 16,000 文字の外部本文追加に対応。**URL 自体が認証情報**で、Web ログインを迂回するため秘密として扱います。 |
| Agent による自己予約 | サーバー側 `scheduled_tasks` で自分の予約を作成/一覧/取消し、tmux などの別ジョブ用に一回限りの復帰 URL を取得。各セッション最大 10 件、未使用 URL は既定 7 日・最大 30 日で失効。一回タスクは配信後に削除します。 |
| OMP 標準キューの再利用 | 時刻/Webhook/手動トリガーは空き時に `prompt`、実行中に `follow_up` として配信し、ビジーや前回配信中を理由にスキップしません。新規セッション型は独立実行。別の永続キューは作りません。 |
| 応答待ち通知 | サイドバーのベルに全セッションの質問、確認、入力、リンク、sudo 要求を集約し、対象へ移動。タブタイトルの件数、閉じたサイドバーの印、許可済みの場合のバックグラウンド OS 通知を追加。入力欄上の質問カードはヘッダー全体のクリックや Enter・Space で繰り返し開閉でき、折りたたむと会話の表示領域が広がります。選択内容とテキスト下書きを保持し、新しい要求は自動展開します。 |
| Web sudo 認証 | Linux の agent コマンドは検証した sudo コマンド行付き Web askpass ダイアログを使用。パスワードはモデルへ渡さず保存/ログ記録しません。接続ページなしなら即拒否、4 分で期限切れ。古い履歴の desktop askpass 等へ戻らない起動時の**ソフト指示**を追加。OS サンドボックスではありません。 |
| メッセージ編集と steer | 送信済みユーザーメッセージ直前で分岐し、元セッションを残して下書きを復元。モバイル送信も steer/キュー設定に従い、キューから Steer へ変更すると OMP 内でも移動します。OMP 18.4+ が必要で、元キューの添付は引き継ぎません。 |
| バックグラウンド結果の折りたたみ | `async-result` は短いプレビューから開始。通知ヘッダー全体のクリックで何度でも開閉でき、フォーカス時は Enter・Space にも対応。矢印は状態を表示します。展開時の改行・字下げと全文コピーを維持し、他のカスタム通知は初期状態で展開します。 |

**長時間ジョブ：**復帰 URL を作成し、tmux 等で独立実行して、終了時に結果を POST すると
同じセッションが処理を続けます。ブラウザーやアイドル中の OMP 子プロセスは開き続ける必要が
ありませんが、**コールバック到着時に ompweb が稼働し到達可能であることが必要**です。
Webhook は停止した Web サーバーを起動できません。生成 URL は設定されたローカルサーバー用で、
別マシンのジョブには安全で到達可能なアドレスの構成が必要です。

時刻は**サーバーのタイムゾーン**を使用。停止中の時刻トリガーは再起動後に一回へ集約して補完し、
無制限に再実行しません。`started` は配信受付であり、キュー内処理の完了ではありません。
実行時間監視はメモリ上のみで再起動後は復元されません。同じ agent ディレクトリーで
複数の ompweb スケジューラーを動かすと重複配信になります。

### 実行ポリシー・配備・安全性

| 追加 / 変更 | 内容と制約 |
| --- | --- |
| 単一 agent 強制 | 全 OMP 起動で設定を検証/追加し、task/バッチ/eval/workpool の組込み子 agent 作成を禁止。通常ツールと過去の子 agent 閲覧は維持。任意プロセスや外部 API を遮断する **OS サンドボックスではありません**。[詳細](docs/CUSTOMIZATIONS.md#single-agent-policy)。 |
| 画像生成の既定値 | Web セッションでは `generate_image` を有効化し、ユーザー/プロジェクトの明示設定を優先。設定変更は次の起動/再起動へ適用。対応する画像生成アカウントが必要。 |
| システムとメモリ保護 | Linux のメモリ/swap/CPU/load、セッション/端末別プロセス、停止と履歴。既定の空き 15% 警告/6% 対処は変更可能。大きな agent/端末の子孫へシグナルと通知を送り、サーバーや無関係プロセスは対象外。カーネル OOM を完全には防げません。 |
| OOM 分離 | agent/端末の OOM スコアを上げ、生成 systemd unit を `OOMPolicy=continue` にして、単一コマンドの OOM 終了による全サービス停止を防ぎます。OMP 自身の保護とは別機構です。 |
| 静かな OMP 更新 | バックグラウンド確認は設定の印のみで起動/復帰を遮りません。ompweb 更新無効でも OMP 更新は可能。失敗理由を保持し、確認は 45 秒待機。実行中は旧バイナリーを継続し、次のアイドル送信前に更新版へ。明示的な全会話再起動は依然中断します。 |
| 段階的 Linux 配備 | [スクリプト](scripts/deploy-linux-service.sh)で別 staging をビルドし、依存/ビルドキャッシュ、ソース指紋、稼働環境、バックアップを利用。`switch` は一致する staging を再利用、なければ先にビルドしてサービス再起動。無停止配備ではありません。 |
| 私設ネットワークと公開範囲 | CLI 起動器は peer/Host を検査してパスワードなし LAN/VPN を許可。同じホストのトンネル/プロキシは境界を迂回できるため、信頼範囲外はパスワードと HTTPS が必要。ローカル認証情報、会話、DB、私的メモ、素材、診断画像はリポジトリーから除外。 |

**互換性と信頼境界：**Wallpaper Engine の完全/画素単位の代替ではなく、未対応 API/形式、
クライアント GPU とブラウザー制約があります。認可済み Web ユーザーは shell と共有状態を
操作でき、マルチユーザー分離ではありません。Wallpaper Engine、Steam/Codex 素材、認証情報、
ASR 重みは**同梱しません**。Web sudo はこのサーバーが起動した OMP 子プロセス用であり、
任意のデスクトップ/端末クライアントには適用しません。

### 既存 Linux サービスの更新

既定の `~/.local/share/ompweb` に `app/` と一つの `runtime/node-*/bin/node` が
構成済みのインストールを対象にします。新規 systemd インストーラーではありません。

```bash
scripts/deploy-linux-service.sh          # staging のみ、稼働サービスは継続
# agent の仕事が終わってから：
scripts/deploy-linux-service.sh switch   # 一致する staging を再利用、なければ先にビルド
```

追跡済みと無視されていない未コミットファイルを含めてコピーし、稼働中 `.env.local` と
サービス設定を維持します。準備後にソース/環境が変われば再ビルドが必要です。
切り替えは管理下の agent と端末を停止します。既定で二つのバックアップと復旧コマンドを保持。
`OMPWEB_INSTALL_ROOT`、`OMPWEB_SERVICE`、`OMPWEB_KEEP_BACKUPS` で変更できます。

## 主な機能

- **リアルタイムチャット**: ローカルの `omp` エージェントとストリーミング対話。
- **キュー削除の確認**: キュー内のフォローアップやステアメッセージをパネルから削除する前に、内容を表示して確認します。OMP 内部ですでにキューに入ったメッセージの配信は取り消しません。
- **セッション管理**: プロジェクトごとに履歴を一覧表示、分岐やフォークにも対応。
- **下書きの復元**: 未送信のテキストを会話または新規セッションのワークスペースごとに保存し、ブラウザストレージが利用可能な場合は、同じタブでの「戻る」「進む」や再読み込み後に復元します（最大 50 件）。画像と添付ファイルはメモリ内にのみ保持されます。
- **ライブ計画と過去のサブエージェント**: Todo と過去の子 agent の要約/記録を表示。このフォークの単一 agent ポリシーは新しい組込み子 agent の作成を禁止し、full ツールプリセットでも迂回できません。
- **ファイル閲覧・編集・管理**: コード、Markdown、画像、音声、PDF をプレビューし、制限付きテキスト編集と作成/改名/削除、元セッションの添付解決に対応。上記の制約を参照してください。
- **Git Worktree サポート**: サイドバーから直接 Git ワークツリーを切り替え・管理。
- **GUI 設定管理**: モデル、API キー、OMP 設定を直接管理。**拡張機能とスキル**に組み込み画像生成、MCP サーバー、スキルの検出・呼出許可・インストール・更新をまとめています。
- **スラッシュコマンド・ショートカット**: `/plan`、`/review`、`/fix`、`/test` などの定型プロンプトとコマンドパレット（既定は `⌘K` / `Ctrl+K`）。**設定 → キーボードショートカット** で全21操作のキーを検索・登録・解除・復元でき、重複する割り当ても表示します。変更は即時に適用され、ブラウザーに保存されてタブ間で同期されます。**タスク停止は既定で未割り当て** のため Esc でタスクは停止しません。停止ボタンか独自の割り当てを使ってください。メニュー・ダイアログの終了、文字編集、フォーカス移動、端末内アプリのキーは変わりません。
- **テーマと多言語対応**: ペーパー調のライト/ダークテーマ、英語・簡体字中国語・日本語に完全対応。

## 環境変数

| 変数名 | 説明 | デフォルト値 |
| --- | --- | --- |
| `PORT` | サーバーポート | `30177` |
| `OMP_WEB_HOSTNAME` | バインドホスト | `127.0.0.1` |
| `OMP_WEB_PASSWORD` | Web ログイン用パスワード | _なし（認証無効）_ |
| `OMP_WEB_NO_OPEN` | `1` でブラウザ自動起動を無効化 | `0` |
| `OMP_WEB_DISABLE_AUTOUPDATE` | `1` で ompweb 自身の更新チェックとアプリ内更新を無効化（OMP ランタイムの確認と更新は引き続き利用可能、変更後は再起動） | `0` |
| `OMP_WEB_OMP_BIN` | `omp` の絶対パス（PATH 未登録時） | _自動検出_ |
| `PI_CODING_AGENT_DIR` | カスタム omp エージェントディレクトリ | `~/.omp/agent` |
| `OMP_WEB_STT_ENDPOINT` | OpenAI 互換の音声認識エンドポイント URL | _なし（無効）_ |
| `OMP_WEB_STT_KEY` | STT エンドポイント用の API キー | _なし_ |
| `OMP_WEB_STT_MODEL` | STT エンドポイント用のモデル名 | _なし_ |
| `OMP_WEB_FFMPEG_BIN` / `OMP_WEB_FFPROBE_BIN` | BGM 抽出用の実行ファイル | PATH の `ffmpeg` / `ffprobe` |
| `OMP_WEB_WALLPAPER_CACHE_MB` | サーバー Scene キャッシュ上限 MiB、`0` で無効 | `4096` |
| `OMP_WEB_WALLPAPER_DIRS` | OS のパス区切りで指定する壁紙ルート、空文字列で Steam 検出無効 | _Steam 自動検出_ |
| `OMP_WEB_WALLPAPER_ASSETS` | 自分の Wallpaper Engine から用意した追加資源ルート | _可能なら自動検出_ |
| `OMP_WEB_CODEX_PETS_DIR` | Codex ペット検出先を上書き | `$CODEX_HOME/pets` または `~/.codex/pets` |
| `OMP_WEB_PORT` | agent 復帰 URL のポート、起動器が設定。開発時は `OMP_WEB_PORT=30178` | `PORT`、なければ `30177` |
